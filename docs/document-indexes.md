# 文档阅读索引

新文档导入时自动建立阅读索引，与文档版本一起发布。单篇新增或更新仅处理该文档，不重新解析整个知识库，也不额外调用 AI。Excel 延续分段处理，保留原始行列坐标和合并范围，不推断空白单元格的含义。

已有文档在知识库详情的「文档索引」中补建。拥有管理权限的用户可以补建缺失索引、重建单篇或全部重建。任务在后台运行，离开页面后仍继续；支持安全取消，已经成功发布的文档保留，尚未发布的临时产物清理，失败文档展示原因。服务重启后未完成任务标记失败，可以重新发起。

手动重建从原文件生成章节、代码对象、成员和表格阅读入口，并从已有向量片段修复关键词索引，不重新计算向量。原文件路径失效时，仅在当前配置的对应知识库投喂目录中查找，并校验内容哈希。原文件缺失会失败；内容已经变化需重新导入，不能把不同版本的原文混入旧索引。

阅读索引采用每篇文档独立的 SQLite 文件，元数据库版本为 17。发布通过事务切换指针；失败或取消保留旧版本。旧的已发布文件在服务启动时清理，避免正在阅读的请求失去文件。已有知识库不会在启动时自动全量补建。

关键词索引改用增量 SQLite FTS5，首次使用时迁移旧 bm25_index.json，保留旧文件。后续添加、替换和删除按片段更新，不再每次重写全部 JSON。迁移旧 JSON 时仍需一次性读取旧文件。

AI 可按名称查找结构、分页列举成员、连续阅读对象，并使用文档内语义或混合搜索。阅读引用绑定文档版本及索引产物，重建后旧引用会失效。对象读完仅表示识别到的边界已读完，不表示业务解释已核验。代码结构识别是启发式解析，不是完整 AST；PDF 可能仍按页分段。全库混合搜索仍受底层候选池限制，分页不表示穷尽全库。

验证使用隔离数据和真实文档副本，未修改生产索引。完整回归曾通过 552 项，最后修订后的相关回归通过 136 项。真实模型成功读取完整 MDSnapshot，但回答仍有把推断表达为确定事实的风险，不能据此声称答案准确性已经解决。
