# 会话整理与展示

侧边栏名称为“会话列表”。用户可创建单层分组，在分组中发起会话、移动会话、重命名和调整分组顺序。旧会话为未分组。删除分组仅将会话移回未分组，搜索跨分组进行。分组只负责归类，不共享上下文或改变知识库授权。

分组属于当前用户，服务端在创建会话和移动会话时校验归属。数据库v19新增session_groups、sessions.group_id和title_source，保留原会话和问答。会话导出携带分组名称，导入时匹配当前用户的同名分组或新建分组，绝不沿用外部用户的分组ID。

会话列表菜单与会话标题旁均可重命名。弹窗居中，可点击外部关闭。手动改名后，自动标题更新由服务端事务内的title_source检查阻止覆盖。既有非默认标题保持为手动标题。

问题和答案上下对齐，两气泡相邻边为直角，间距4px，问答组间距20px。检索过程和引用保留在答案气泡内。答案下方展示本轮原始提问时间，来自turns.created_at；扩展检索不改变这个时间。

登录后的全局外观逻辑应用用户的背景选择，不再依赖设置页挂载。无选择时macOS主题为Moonlit Mint；已保存选择继续保留。登录前使用默认背景，不读取其它用户的背景。

知识库仍通过ID和独立集合区分。不同用户私有库可同名，同一用户私有库内、团队库内新增或改名时检查重名（忽略首尾空白和英文字母大小写）。已有重名保留，列表附加短ID消歧。知识库列表、选择器和会话知识库提示显示个人归属或团队标识；归属/范围转换也校验目标命名范围。授权页面原有所有者标识保留。

验证使用隔离临时数据库和模拟API的浏览器；不对真实会话或知识库做验证性写入。后端重启后执行新增字段迁移。
