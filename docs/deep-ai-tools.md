# 深度 AI 知识库工具

六项能力：查看知识库、查找文档、全库搜索、文档内搜索、查看结构、阅读原文。研究记录和历史工具保持可选。工具描述说明用途、参数来源、返回内容和边界，模型自主选择，不新增核验调用。

初始目录在当前授权知识库中按问题与文件名关键词相关性排列，最多12条、约4500字符；目录不完整时明确标记，可继续分页查找或全库搜索。不是正文召回或事实证据。

全库搜索 schema 不含 document_id；search_document 要求真实文档编号，支持 related 和 exact（大小写不敏感的字面匹配），返回搜索范围和精确匹配chunk数。旧直接调用参数在内部兼容，不向新工具schema暴露。

目录、搜索返回 request-local read_ref。read_document 直接使用标识；next_read_ref 继续章节，next_section_ref 读取相邻章节。每次使用仍检查知识库权限、文件版本和成员关系。标识随本轮工具工作区交接，超时工作线程无法把标识或原文写回活动请求。

搜索片段围绕匹配位置截取；正文坐标保留，行号说明是chunk或section局部行号。代码声明只提供语法线索，不充当完整AST。PDF章节可能仍是页或解析分段，提供相邻章节阅读入口，不把一页读完当作业务定义完整。

表格返回原文、可识别的Markdown表头、对应行及列数校验；不同表分别提供，不跨段落复用旧表头。结构元数据有界，截断有标记，未完整读取的行不额外补出尾部。没有重新解析原始Excel，不推定缺失的合并单元格、多级表头或空白值。结构信息和范围提示进入最终证据包，避免在查阅与作答之间丢失。

日志沿用 knowledge_tool 保存参数、阅读标识、原文及结构信息；文档缺失、未入库、版本变化、章节不存在和阅读标识无效有不同错误码。无结果与失败分开。目录及结构化结果改善工具可用性，不代表已独立核验模型结论。


## 查阅与作答衔接

正常作答沿用完整原生工具会话（调用、结果、已有分析和本轮会话历史），使用同一套工具定义但禁止继续调用，流式输出最终答案。不会在查阅结束后无条件重建独立资料包。只有上下文容量不足或查阅异常时，才使用有界资料包，并携带已有文本分析；容量省略和衔接模式会写入日志与阶段事件。

同一文档版本、同一章节、坐标一致且逐字包含的重复片段，通过 text_reference 指向此前已发送的原文；不删除原始来源快照，不跨版本合并，也不切除部分重叠后的上下文。阅读分页优先在末尾附近的段落或行边界结束；超长单行仍按上限分页，可继续读取。

## 文档索引与自主流式调用更新

本节取代上文旧的“正常作答禁止继续调用”流程描述。正常轮次使用同一条流式工具会话：模型可以选择继续调阅，也可以直接输出答案，不再额外发起一次最终回答请求。只有达到轮次或时间预算等退出条件时，才进入禁止工具的收尾请求。公开文本实时输出，隐藏推理不展示；输出后断流保留部分文本并记录未完成，不自动重播造成重复。

导入自动生成原文阅读索引，旧文档支持后台补建和单篇重建，详见 [文档索引](document-indexes.md)。索引可用时，目录和阅读使用原文章节及对象边界；未补建文档继续使用原有片段入口。Excel 索引保存原始单元格坐标和合并范围，取代旧描述中的仅从 Markdown 推断结构。

文档内搜索增加 identifier、semantic、hybrid 模式，全库搜索也区分关键词、精确、标识符及语义用途。工具说明提供参数来源、适用场景、返回范围和继续阅读方法，由模型自主选择；不新增强制业务核验流程。
