# 摘要执行策略与流式生成（本地待验收）

设置 → AI 运行配置集中提供通用连接、问答生成、文档摘要与全局概览。导入自动摘要开关仅控制导入行为，不关闭手动全局概览。摘要读取等待默认继承通用连接设置；摘要步骤时长包含网络重试与截断补偿，任务时长限制整个后台任务。

配置唯一默认值与校验定义在 `src/core/summary_policy.py`。现有 `ingest.ai_summary` 字段保留；新增字段通过缺省值兼容旧配置。`config.local.yaml` 的覆盖来源在页面显示，被覆盖的字段不能通过页面改成与覆盖文件冲突的值。API/模型编辑可选填写上下文容量及输出上限，未知保持空；这些是用户提供的约束，不是服务商能力认证。摘要按已知输出上限限制额度，输入使用保守字符预算，不能保证与所有服务商的 token 计数完全一致。

新任务保存有效策略快照（不含凭据）。修改设置只影响后续任务。旧 `budget` 字段仍是逻辑调用预算；新版 `request_limit` 控制实际请求尝试，包含重试/补偿，前端提交兼容逻辑上限并明确展示请求上限。命中缓存不计请求。

摘要使用现有账号模型链路流式接收，在后台收集完整正文。结束原因缺失、异常断流、流内错误、截断、空正文均不能发布；截断仅允许一次真正增额补偿。流式部分输出失败后，重试丢弃部分正文，不拼接。网络重试、输出补偿和 JSON 修复分别有有限次数，并共同受到请求预算与任务期限限制。

任务取消每 0.5 秒检查一次（不含数据库检查及连接关闭耗时），即使尚无正文也会取消读取并关闭本地连接；不保证服务商同步停止计费。普通问答仍保留输出后的既有重试规则。

已有有效文档摘要继续复用；文档概览与分段检查点继续使用原有存储。新增分组汇总检查点按实际输入、来源标签、API/模型、提示词版本及生成配置隔离。只有有效且收敛的汇总才缓存。收到 504 且网络重试耗尽后，可按配置仅拆分失败组；不自动改 API 或模型，不截去来源。缓存命中刷新保留时间，默认保留 90 天，创建该知识库任务时清理过期检查点；正式文档摘要不参与此清理。

预览使用执行端相同分组函数，并识别完整已知输入的汇总缓存。缺失文档摘要和未知层级输出仍只能估算；请求上限才是执行约束，不把预计次数承诺为费用上限。

## 数据兼容与回退

新增 `summary_job_policies`（策略快照与请求计数）、`api_model_limits`（可选模型约束），不改原有摘要正文表和模型目录列。旧客户端未提交新增配置字段时保留现值；未提交模型约束时保留现值。旧任务重启后沿用 interrupted 恢复逻辑，不自动重跑模型。

部署前备份数据库和配置，并确认没有活动任务。回退时停止新任务、恢复旧代码及配置；新增表可保留，旧代码会忽略。旧全局概览在失败或取消时保留。176 的容器内临时补丁不在本次变更范围，后续升级需单独迁移其运行参数，不将临时大额度写进所有安装的默认配置。

## 验收

隔离测试覆盖流式部分输出后重试、静默期间取消、缺失终止事件、截断达到额度上限、汇总缓存续建、任务策略冻结、实际请求预算、设置持久化与写入失败、旧模型客户端兼容、权限与摘要过期检测。

本地人工验收：进入 AI 运行配置检查新字段；修改并保存后刷新确认；检查知识库生成预览；生成全局概览观察流式任务进度；取消/重试检查缓存复用。模型真实响应与上游约 300 秒限制仍需要实际生成验收，本轮自动测试不调用收费模型。
